# Product Guidelines

## 言語

- UI 文言は英語とする。`plugin.xml` と `messages/MyBundle.properties` が英語で記述されているため、既存の方針に合わせる。
- 開発者向けドキュメントと Conductor の成果物は日本語とする。リポジトリの `AGENTS.md` に準拠する。

## ボイスとトーン

- 簡潔で実用的な表現を用いる。開発者が操作結果を素早く判断できる文言を優先する。
- 誇張表現と曖昧な表現を避ける。機能が未実装である場合はその旨を明示する。
- エラーメッセージでは、発生した事象と利用者が取れる次の行動を伝える。

## UX 原則

- IntelliJ Platform の UI ガイドラインに準拠する。
- ツールウィンドウは IDE 標準の操作感に合わせ、既存のショートカットとレイアウトを壊さない。
- 長時間の処理は進捗を表示する。UI スレッドをブロックしない規則は `code_styleguides/architecture_rules.md` の「IntelliJ Platform の制約」を参照。
- サンプル実装を製品機能と誤認させない。テンプレート由来の文言は実装時に置換する。

## ドキュメント

- コードのコメントは「何をしたか」ではなく「なぜそうしたか」を書く。
- 仕様が変わった場合は、関連する Conductor ドキュメントを同じ変更で更新する。
